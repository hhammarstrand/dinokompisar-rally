# Dinokompisar Rally

Webbaserat SNES-kart i Dinokompisar-dalen. Statiskt, hostat på GitHub Pages.

Spela: https://hhammarstrand.github.io/dinokompisar-rally/

## Styra

- Pilar eller WASD — gas, broms, styr
- Mellanslag — använd item
- Mobil: vänster halva styr, höger halva gas/broms

## Karaktärer

Dino, Rex, Stega, Laga.

## Banor

1. Den ljusa grottan
2. Den mörka skogen
3. Molntoppen

3 varv, 3 CPU. Items: vänskapssten, ägg, lövhög, dimma.

## Utveckling

```bash
npm install
npm test
npm run dev
npm run build
```
